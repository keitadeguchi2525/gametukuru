# パリィ・ハンター 仕様メモ（v16）

遊ぶ：https://keitadeguchi2525.github.io/gametukuru/ ／ 手元では `index.html` を開く

## コアループ
1. ダンジョンに潜入 → 各階の敵と1対1で戦う
2. **矢印は出ない**。敵のモーションから攻撃が来る方向を読み、**その方向へはじき返す**ようにスワイプでパリィ（8方向、判定は±30°）
   - 例：上から振り下ろし → 上へスワイプ／右下から斬り上げ → 右下へスワイプ／右から薙ぎ払い → 右へスワイプ
   - 読み取りのヒント：攻撃する手足（翼・腕）が来る側へ大きく振りかぶる＋その部位だけ強く光る。本体も来る側へ少し寄る
   - **タイミングの輪は攻撃が来る場所に表示**。輪が縮んで黄色になったら受付中
   - 画面中央の文字は「斬撃！」「強撃！」「3連撃 2/3！」など種類だけ。方向は出さない（失敗時のみ正解方向を表示）
   - PC：パリィはマウスのスワイプ（ドラッグ）だけ（キーボードでのパリィはなし）。回避は **A＝左／D＝右**（画面の左下・右下の回避ボタンも可）
3. 有効受付: 着弾0.3秒前（溜めが短い攻撃は溜めの45%まで）〜0.12秒後／PERFECT: ±0.085秒（崩し時間 +0.6秒）
   - **パリィに失敗すると0.5秒間は回避できない**（回避ボタンが灰色になり✕が出る。輪の文字も「失敗… 0.4秒 回避できない」）。**連撃の途中の失敗は例外**で、すぐ回避できる
4. **体勢ポイント**が必要量に届くと「体勢崩し」→ この間だけ攻撃が通る（詳しくは「体勢ポイント」）。被弾すると -25pt
5. 攻撃: 敵の部位を押したまま「こする」と連続ヒット（約42px動くごと、最短0.095秒間隔）。速くこするほど強い
6. 部位HPをゼロ → 部位破壊で素材獲得（目安：普通の武器で1戦2か所、部位ダメージ+の武器なら3か所も狙える）
7. 討伐で通常ドロップ＋レア判定

## 攻撃スピード
- 溜め時間：各敵の基準値 ×0.72（強撃×1.4、ブレス×0.8）
- 冥王ネクロスの基準値は 0.8秒（v16で0.7秒から少し遅くした）
- 攻撃の間隔：基準値 ×0.5、連続攻撃のつなぎ 0.16秒
- パリィ後の硬直 0.22秒／被弾後 0.3秒
- 回避の受付：着弾0.22秒前〜0.12秒後（v16で0.3秒前から短縮）。回避のクールタイム 0.45秒
- **回避は左右の2方向**（v16）。ブレス／投擲は飛んでくる側の反対へよける。普通の攻撃と落下物はどちらへよけてもよい
- **回避に成功すると0.6秒間無敵**（`INVINCIBLE`）。ただし効くのは**落下物がからむときだけ**：攻撃をよけた直後の落下物／落下物をよけた直後の攻撃・落下物は当たらない。攻撃をよけた直後の攻撃（連撃の次の一撃・投擲など）には効かない。空振りの回避では無敵にならない。無敵が効く場面では体のまわりが水色に光り、体が点滅する

## 敵の攻撃パターン
| 種類 | 内容 | 対処 | 被ダメ倍率 |
|---|---|---|---|
| 通常斬り | 8方向のどこかから | 来た方向へはじく（体勢+25pt） | ×1 |
| 強撃 | 赤く光る大振り、溜め長め | 来た方向へはじく（体勢+50pt） | ×1.6 |
| ディレイ | 溜めが途中で0.3〜0.55秒止まる | 焦らず待ってはじく。**釣られて早くスワイプすると、その攻撃は回避もできない** | ×1 |
| ブレス/投擲 | 口元に⚠と点線の輪。**プレイヤーの左側か右側に飛んでくる**（着弾する側に赤い点線、よける側に緑の矢印）。パリィ不可。溜めは基準×0.8（ゴルム約0.6秒、ネクロス約0.46秒） | **反対側へ回避**（左側に来たら右回避）。逆によけると当たる。受付は着弾0.22秒前〜0.12秒後 | ×1.35 |
| 連撃 | 中央に回数の並び（●＝斬撃、⚠＝ブレス/投擲）だけ表示（大きさは `FLURRY_UI`、1マス46px。せまい画面では縮む）。方向はモーションで読む。2発目以降は30%でブレス/投擲 | ●ははじく、⚠は回避（⚠の下の矢印がよける方向）。全部さばくと体勢+25pt。●を回避でよけると、回避ビルドでなければ体勢は増えず、その連撃のボーナスもなし（回避ビルドなら回避もさばいた扱い）。崩しは連撃の最後に発生 | 1発×0.6（ブレスは×1.35×0.6） |

## 落下物（v16。ダンジョンごと）
ボスや雑魚の攻撃とは別に、頭上から降ってくる。**パリィ不可・回避でのみ避けられる**（左右どちらへよけてもよい）。約1.15秒で落ち、当たると 攻撃力×1.5 の大ダメージ＋体勢-25pt。頭上で予兆（震える・雲が集まる・魔法陣など）、足元の印がだんだん濃くなり、受付に入ると⚠がピンクに。体勢崩し中・鱗粉の玉の間は降らない。回避ビルドなら回避でも体勢pt。

| ダンジョン | 落ちてくるもの | ボス戦の間隔（目安） |
|---|---|---|
| ★1 岩窟の迷宮 | 落石 | 約15秒に1回 |
| ★2 妖蛾の森 | なし | - |
| ★3 雷鳴の峡谷 | 落雷（黒雲が集まって稲妻） | 約13秒に1回 |
| ★4 氷霧の霊廟 | 落氷（つらら） | 約10秒に1回（25%で2本連続。グラシエルのHP50%以下は50%） |
| ★5 冥界の塔 | 闇の光線（足元の魔法陣から紫の光の柱） | 約7.5秒に1回 |

- 間隔は目安の0.8〜1.2倍でばらつく。雑魚戦はボス戦の1.5倍の間隔（少なめ）
- 数値は `HAZARDS`（ダンジョンid → 種類・名前・間隔・2連続の確率）

境目のルール：形態変化（ネクロスHP50%）と岩鎧（ゴルムHP60%）の境目は一撃で飛び越えられず、達した瞬間に体勢崩しは強制キャンセル。ボスは咆哮（約1.4秒）してから再開。

## ダンジョン（全ロスト制）
- 戦利品は帰還するまで未確定。階をクリアするたびに「帰還」か「次の階へ（最大HPの20%回復。`FLOOR_HEAL`）」を選ぶ。HPは持ち越し
- **倒れると、その探索の戦利品をすべて失い、装備中の5つ（武器＋防具4部位）からランダムに1〜3つを失う**（1つ＝33%／2つ＝33%／3つ＝34%。初期装備が選ばれた場合は消えず強化+0に戻る）
- 戦闘中に逃げる「脱出」はなし（v16で削除）。帰るときは階の合間の「帰還」だけ
- **ポーズ**（v16）：戦闘中、**左上**の「❚❚」ボタン（PCは Esc か P キー）で一時停止。ブラウザを裏に回したときも自動でポーズ。ポーズ画面から「戦闘に戻る」か「あきらめて帰る（敗北扱い）」を選べる。**効果音／BGM の切り替えもポーズ画面の中**（拠点と同じボタン）。あきらめると確認のあと、倒れたときと同じ扱い（戦利品を失い、装備1〜3つを失う。ボス直行のテストでは装備は失わない）
- 最奥のボスを倒すと踏破＆次のダンジョン解放。雑魚は階が進むごとに HP・部位HP +12%、攻撃 +6%

拠点のダンジョン一覧は**名前と説明文だけ**。まだ解放されていないダンジョンは**星の数だけ**出して、名前と説明は「???」。敵の名前・ボスのギミックは表示しない。「詳細を表示」を押すと、手に入る素材の名前（数の目安は出さない）と、レア素材が1回踏破で出る確率（全階ぶん合算）が出る。工房にも素材の目安（何回踏破分か）は出さない。
解放：1つ前のダンジョンを踏破すると解放（★の順）。

## ビルド（v16）
| ビルド | 長所 | 短所 |
|---|---|---|
| バランス | クセがない | 特になし |
| パリィ特化 | パリィ1回の体勢ptが多い（+20〜50%）→ 崩しやすい | 攻撃力が低め |
| クリティカル | 会心率・会心ダメージが上がる（基本は会心率10%・×1.8。v16で毒蛾一式は会心率60%・氷晶一式は80%になるよう強化。会心率の上限は100%） | パリィの体勢ptが減る（-10〜20%）→ 崩しにくい |
| 回避 | 回避成功でも体勢ptが入る。連撃の●を回避してもボーナスが消えない。**回避カウンター**（下） | 回避の受付時間が少し短くなる（武器・防具それぞれ -5〜8%。一式で約0.87倍） |

- **回避カウンター**（v16）：回避ビルド（回避で体勢ptが入る装備）で回避に成功すると、0.5秒（`COUNTER_TIME`）だけ、崩していなくても敵をこすって攻撃できる。ダメージは ×0.2（`COUNTER_MUL`）。画面のふちが水色に光り「カウンター！ こすって攻撃」と出る
- v16の回避ビルド調整：簡単なシミュレーターで「同じ腕前の人がボスを倒すまでの時間」を比べ、パリィ特化とほぼ同じ（約0.95〜1.0倍）になるようにした。いちばん効いたのは受付の短縮をゆるめたこと
- 効果は武器と防具の合計（倍率は掛け算、会心率や回避ptは足し算）。工房の上に「いまのビルド」として数値が出る
- 防具の「一式」効果は、そろえた部位の割合ぶんだけ効く（頭25%・胴35%・手15%・足25%。4部位そろえると100%）

## 持ち物の画面（v16）
- 拠点のタブ：ダンジョン／工房／ガチャ／**持ち物**／ステータス／遊び方（「素材」タブは持ち物の中へ）
- 持ち物の小タブ：**武器**（持っている武器の一覧。ここから装備できる。いまのビルドの数値も出る）／**防具**（頭・胴・手・足ごとに持っている防具の一覧を**2列**で表示。ここから装備できる。防御と体力の合計も出る）／**素材**（持っている素材とデータのリセット）
- 防具の小タブには「**シリーズでまとめて装備**」のボタンが並ぶ（持っている部位が1つ以上あるシリーズだけ。「岩甲（4/4）」のように持っている部位の数も出る）。押すと、そのシリーズで持っている部位をまとめて装備する（持っていない部位はいまのまま）。全部装備中のシリーズは緑で ✔
- 装備中のものは**いちばん上**に並ぶ
- 装備中のカードは、工房・持ち物どちらでも**緑に光る太い枠**と、上のふちの「✔ 装備中」のリボンで目立たせる
- 作成と強化は工房で

## 画面演出
- **ボス前の WARNING!!**（v16）：ボス階に入ると、戦闘が始まる前に約2.6秒（`WARN_TIME`）の警告演出。画面が赤く点滅し、黄色と黒のしま模様に「WARNING ▲」の文字が流れる帯が上下に2本、まん中に大きく「WARNING!!」、下に「BOSS（ボス名） 出現」。サイレンの効果音（`sfx('warning')`）。演出のあいだボスは攻撃せず、落下物も降らず、時間（必要ポイントの増加など）も進まない。終わるとボスが咆哮し、約1.0秒（`WARN_AFTER`）で最初の攻撃が来る
- 戦闘中の上の表示（v16で見やすく整理）：いちばん上の段に 左上の❚❚（ポーズ）ボタン／まん中に「ダンジョン名・階・戦利品の数」。その下に敵の名前・体力・体勢。文字には黒いふちどりをつけ、ギミックの説明文には半透明の帯を敷いて、敵の絵と重なっても読めるようにしている。自分のHPは左下で大きめに表示
- 拠点：タブの文字が折り返さないようにし、説明文・タグ・ボタンの文字を少し大きく明るくした
- バージョン表記：画面の左下に小さく「パリィ・ハンター v16.23（2026/11/16 更新）」のように出す。「v16」は `VERSION`（このメモの番号と合わせる）、「.23」は **GitHub の main に入った更新（コミット）の数を自動で取得**、日付は main の最後の更新日。つながらないときは前回の値（なければ「v16」だけ）。戦闘中はHPの表示を少し上にずらして重ならないようにしている
- 低体力の赤いトンネル：プレイヤーの体力が85%を切ると、画面の周りから赤い影が迫ってくる。体力が減るほど濃く・内側まで広がり、35%を切ると鼓動のように脈打つ（瀕死に近いほど速い）。60%を切るあたりから血管のような筋も出る。HUDの文字はこの上に描くので読める（`drawLowHP()`、出はじめは `LOWHP_START`）

## サウンド（v15）
音声ファイルは使わず、Web Audio API でその場で合成。ブラウザの決まりで、最初のタップ／キー入力から鳴る。

スマホ対策（v16）：最初のタッチ（pointerdown／touchstart／touchend／click）で音を準備し、無音を一瞬鳴らして再生を許可させる。iPhone の消音スイッチがONでも鳴るよう、`navigator.audioSession.type='playback'` と無音の `<audio>` のループ再生で「再生用」の音にしている。**ブラウザを裏に回したとき（ホームに戻る・別のアプリやタブに切り替える・画面を消す）は音を全部止める**（AudioContext を一時停止し、無音の `<audio>` も止める。隠れている間はタッチしても鳴らない）。画面に戻ったら自動で再開。拠点の「効果音／BGM」ボタン、戦闘中はポーズ画面の「効果音／BGM」ボタンで切り替え（設定はブラウザに保存）。
