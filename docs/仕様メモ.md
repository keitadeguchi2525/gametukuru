# パリィ・ハンター 仕様メモ（v13）

遊ぶ：https://keitadeguchi2525.github.io/gametukuru/ ／ 手元では `index.html` を開く

## コアループ
1. ダンジョンに潜入 → 各階の敵と1対1で戦う
2. **矢印は出ない**。敵のモーションから攻撃が来る方向を読み、**その方向へはじき返す**ようにスワイプでパリィ（8方向、判定は±30°）
   - 例：上から振り下ろし → 上へスワイプ／右下から斬り上げ → 右下へスワイプ／右から薙ぎ払い → 右へスワイプ
   - 読み取りのヒント：攻撃する手足（翼・腕）が来る側へ大きく振りかぶる＋その部位だけ強く光る。本体も来る側へ少し寄る
   - **タイミングの輪は攻撃が来る場所に表示**。輪が縮んで黄色になったら受付中
   - 画面中央の文字は「斬撃！」「強撃！」「3連撃 2/3！」など種類だけ。方向は出さない（失敗時のみ正解方向を表示）
   - PCキー：矢印/WASD、斜めは Q・E・Z・C（＝はじく方向）、回避は **Shift**（画面右下の回避ボタンも可）
3. 有効受付: 着弾0.3秒前（溜めが短い攻撃は溜めの45%まで）〜0.12秒後／PERFECT: ±0.085秒（崩し時間 +0.6秒）
4. 規定回数パリィ成功で「体勢崩し」→ この間だけ攻撃が通る。被弾すると体勢ゲージ-1
5. 攻撃: 敵の部位を押したまま「こする」と連続ヒット（約42px動くごと、最短0.095秒間隔）。速くこするほど強い
6. 部位HPをゼロ → 部位破壊で素材獲得（目安：普通の武器で1戦2か所、部位ダメージ+の武器なら3か所も狙える）
7. 討伐で通常ドロップ＋レア判定

## 攻撃スピード
- 溜め時間：各敵の基準値 ×0.72（強撃×1.4、ブレス×0.8）
- 攻撃の間隔：基準値 ×0.5、連続攻撃のつなぎ 0.16秒
- パリィ後の硬直 0.22秒／被弾後 0.3秒
- 回避のクールタイム 0.45秒

## 敵の攻撃パターン
| 種類 | 内容 | 対処 | 被ダメ倍率 |
|---|---|---|---|
| 通常斬り | 8方向のどこかから | 来た方向へはじく（体勢+1） | ×1 |
| 強撃 | 赤く光る大振り、溜め長め | 来た方向へはじく（体勢+2） | ×1.6 |
| ディレイ | 溜めが途中で0.3〜0.55秒止まる | 焦らず待ってはじく | ×1 |
| ブレス/投擲 | 口元に⚠と点線の輪。パリィ不可。溜めは基準×0.8（ゴルム約0.6秒、ネクロス約0.4秒） | 回避（着弾0.3秒前〜0.12秒後） | ×1.35 |
| 連撃 | 中央に回数の並び（●＝斬撃、⚠＝ブレス/投擲）だけ表示。方向はモーションで読む。2発目以降は30%でブレス/投擲 | ●ははじく、⚠は回避。全部さばくと体勢+1。崩しは連撃の最後に発生 | 1発×0.6（ブレスは×1.35×0.6） |

連撃の発数：石ころ獣2／苔岩獣・雷仔竜・ゴルム 2〜3／嵐飛竜・亡霊騎士・ヴォルガ 3〜4／骸骨魔導士 3〜5／ネクロス 4〜5

## 被ダメージ（適正装備で通常攻撃1発 ≒ 最大HPの1/3）
被ダメージ = 敵の攻撃力 × 攻撃の倍率 × 100 ÷ (100 + 防御合計)

適正装備の想定：岩窟の迷宮＝岩甲一式+0（防御10・HP108）／雷鳴の峡谷＝雷鱗一式+0（防御18・HP115）／冥界の塔＝雷鱗一式 各+3（防御30・HP127）

## ボスギミック
| ボス | ギミック | 攻略のポイント |
|---|---|---|
| 岩甲獣ゴルム | 【岩鎧】HP60%で発動。与えるダメージ1/5。形態変化後3回目の体勢崩しで砕ける | 砕けた瞬間 攻撃力×3 のダメージ |
| 雷竜ヴォルガ | 【雷鳴乱舞】雷ゲージ（約16秒）が溜まると、はじく方向5つを2.4秒だけ見せる → ヒントなしで高速5連撃 | 全部パリィで即体勢崩し（+2秒）。雷角を折るとゲージの溜まりが半分 |
| 冥王ネクロス | 【冥核再生】冥核が無事な間、毎秒最大HPの0.4%回復（部位も）／【第二形態】HP50%で攻撃がさらに速く／【反転の呪い】第二形態中、紫の輪の攻撃は逆方向にはじく | 先に冥核を壊すと再生が止まる |

境目のルール：形態変化（ネクロスHP50%）と岩鎧（ゴルムHP60%）の境目は一撃で飛び越えられず、達した瞬間に体勢崩しは強制キャンセル。ボスは咆哮（約1.4秒）してから再開。

## ダンジョン（全ロスト制）
- 戦利品は帰還するまで未確定。階をクリアするたびに「帰還」か「次の階へ（最大HPの5%回復）」を選ぶ。HPは持ち越し
- **倒れると、その探索の戦利品＋装備中の武器と防具4部位をすべて失う**（初期装備は消えず強化+0に戻る）
- 戦闘中の「脱出」：その階の戦利品だけ失う。装備は失わない
- 最奥のボスを倒すと踏破＆次のダンジョン解放。雑魚は階が進むごとに HP・部位HP +12%、攻撃 +6%

| ダンジョン | 構成 |
|---|---|
| 岩窟の迷宮（全5階） | 石ころ獣 ×2 → 苔岩獣 ×2 → BOSS 岩甲獣ゴルム |
| 雷鳴の峡谷（全5階） | 雷仔竜 ×2 → 嵐飛竜 ×2 → BOSS 雷竜ヴォルガ |
| 冥界の塔（全6階） | 亡霊騎士 ×2 → 骸骨魔導士 ×3 → BOSS 冥王ネクロス |

## 素材の経済
- 武器1本＝そのダンジョン約2回踏破分、防具一式（4部位）＝約3回踏破分の素材（コード内で自動計算）
- 前提：全階の討伐ドロップ平均＋1戦につき部位破壊1か所。レア素材は別
- 強化はそのダンジョンで一番多く出る素材（岩窟＝獣骨／峡谷＝雷鱗／冥界＝冥布）。武器+5まで約1回分、防具一式+5まで約1.5〜2.5回分
