# パリィ・ハンター 仕様メモ（v16）

遊ぶ：https://keitadeguchi2525.github.io/gametukuru/ ／ 手元では `index.html` を開く

## コアループ
1. ダンジョンに潜入 → 各階の敵と1対1で戦う
2. **矢印は出ない**。敵のモーションから攻撃が来る方向を読み、**その方向へはじき返す**ようにスワイプでパリィ（8方向、判定は±30°）
   - 例：上から振り下ろし → 上へスワイプ／右下から斬り上げ → 右下へスワイプ／右から薙ぎ払い → 右へスワイプ
   - 読み取りのヒント：攻撃する手足（翼・腕）が来る側へ大きく振りかぶる＋その部位だけ強く光る。本体も来る側へ少し寄る
   - **タイミングの輪は攻撃が来る場所に表示**。輪が縮んで黄色になったら受付中
   - 画面中央の文字は「斬撃！」「強撃！」「3連撃 2/3！」など種類だけ。方向は出さない（失敗時のみ正解方向を表示）
   - PCキー：矢印/WASD、斜めは Q・E・Z・C（＝はじく方向）、回避は **Shift**（画面右下の回避ボタンも可）
3. 有効受付: 着弾0.3秒前（溜めが短い攻撃は溜めの45%まで）〜0.12秒後／PERFECT: ±0.085秒（崩し時間 +0.6秒）
4. **体勢ポイント**が必要量に届くと「体勢崩し」→ この間だけ攻撃が通る（詳しくは「体勢ポイント」）。被弾すると -25pt
5. 攻撃: 敵の部位を押したまま「こする」と連続ヒット（約42px動くごと、最短0.095秒間隔）。速くこするほど強い
6. 部位HPをゼロ → 部位破壊で素材獲得（目安：普通の武器で1戦2か所、部位ダメージ+の武器なら3か所も狙える）
7. 討伐で通常ドロップ＋レア判定

## 攻撃スピード
- 溜め時間：各敵の基準値 ×0.72（強撃×1.4、ブレス×0.8）
- 攻撃の間隔：基準値 ×0.5、連続攻撃のつなぎ 0.16秒
- パリィ後の硬直 0.22秒／被弾後 0.3秒
- 回避のクールタイム 0.45秒

## ダンジョン（全ロスト制）
- 戦利品は帰還するまで未確定。階をクリアするたびに「帰還」か「次の階へ（最大HPの5%回復）」を選ぶ。HPは持ち越し
- **倒れると、その探索の戦利品をすべて失い、装備中の5つ（武器＋防具4部位）からランダムに1〜3つを失う**（1つ＝33%／2つ＝33%／3つ＝34%。初期装備が選ばれた場合は消えず強化+0に戻る）
- 戦闘中の「脱出」：その階の戦利品だけ失う。装備は失わない
- 最奥のボスを倒すと踏破＆次のダンジョン解放。雑魚は階が進むごとに HP・部位HP +12%、攻撃 +6%

拠点のダンジョン一覧は**名前と説明文だけ**。敵の名前・ボスのギミックは表示しない。「詳細を表示」を押すと、1回踏破あたりの素材の目安数と、レア素材が1回踏破で出る確率（全階ぶん合算）が出る。
解放：1つ前のダンジョンを踏破すると解放（★の順）。

## ビルド（v16）
| ビルド | 長所 | 短所 |
|---|---|---|
| バランス | クセがない | 特になし |
| パリィ特化 | パリィ1回の体勢ptが多い（+20〜50%）→ 崩しやすい | 攻撃力が低め |
| クリティカル | 会心率・会心ダメージが上がる（基本は会心率10%・×1.8） | パリィの体勢ptが減る（-10〜20%）→ 崩しにくい |
| 回避 | 回避成功でも体勢ptが入る。連撃の●を回避してもボーナスが消えない | 回避の受付時間が短くなる（-15〜35%） |

- 効果は武器と防具の合計（倍率は掛け算、会心率や回避ptは足し算）。工房の上に「いまのビルド」として数値が出る
- 防具の「一式」効果は、そろえた部位の割合ぶんだけ効く（頭25%・胴35%・手15%・足25%。4部位そろえると100%）

## 素材の経済
- 武器1本＝そのダンジョン約2回踏破分、防具一式（4部位）＝約3回踏破分の素材（コード内で自動計算）
- 前提：全階の討伐ドロップ平均＋1戦につき部位破壊1か所。レア素材は別
- 強化はそのダンジョンで一番多く出る素材（岩窟＝獣骨／森＝鱗粉／峡谷＝雷鱗／霊廟＝霜鱗／冥界＝冥布）。武器+5まで約1回分、防具一式+5まで約1.5〜2.5回分

## 画面演出
- 低体力の赤いトンネル：プレイヤーの体力が85%を切ると、画面の周りから赤い影が迫ってくる。体力が減るほど濃く・内側まで広がり、35%を切ると鼓動のように脈打つ（瀕死に近いほど速い）。60%を切るあたりから血管のような筋も出る。HUDの文字はこの上に描くので読める（`drawLowHP()`、出はじめは `LOWHP_START`）

## サウンド（v15）
音声ファイルは使わず、Web Audio API でその場で合成。ブラウザの決まりで、最初のタップ／キー入力から鳴る。拠点の「効果音／BGM」ボタン、戦闘中は左上の「♪」で切り替え（設定はブラウザに保存）。

| 場面 | 効果音 |
|---|---|
| UI | ボタンのクリック、タブ切り替え、作成（上昇するアルペジオ）、強化（金属音＋チャイム）、装備 |
| パリィ | 成功（金属のカキン）、PERFECT（高いチャイム付き）、強撃パリィ（重い音）、失敗（にぶい音） |
| 回避 | 回避の風切り音、回避成功のチャイム |
| 敵の攻撃 | 振り抜きの風切り、強撃の溜めのうなり、ブレスの溜め、岩の落下・落雷・炎の着弾、被弾（強撃は重く） |
| 攻撃 | こすり攻撃のヒット、会心、部位破壊、体勢崩し、撃破 |
| 報酬・結果 | レアドロップのきらめき、階クリア、踏破ファンファーレ、力尽きた、脱出 |
| ギミック | 岩鎧（地鳴り）、ヒビ／粉砕、雷速モード（雷鳴）、雷光転移（バチッ）、第二形態の咆哮、反転の呪い、必要ポイント増加の警告、鱗粉の玉（出現・撃ち落とし・破裂）、つらら（きしみ・落下の砕ける音） |
| 瀕死 | 体力35%未満で心臓の鼓動（減るほど速い） |

| BGM | 雰囲気 |
|---|---|
| 拠点 | ゆったりしたアルペジオとパッド（76BPM） |
| 岩窟の迷宮 | 低いベースと重い太鼓（100BPM）／ボス階は120BPM |
| 妖蛾の森 | 長調寄りの軽いアルペジオ（92BPM）／ボス階は116BPM |
| 雷鳴の峡谷 | 速いベースと刻むハイハット（128BPM）／ボス階は142BPM |
| 氷霧の霊廟 | 澄んだ高いアルペジオと長いベース（80BPM）／ボス階は126BPM |
| 冥界の塔 | 不穏な和音と鐘のようなアルペジオ（84BPM）／ボス階は100BPM |
撃破・力尽きた・脱出の瞬間にBGMを止め、効果音を目立たせる。音量は `SFX_VOL`／`BGM_VOL`、曲は `SONGS` で変えられる。
