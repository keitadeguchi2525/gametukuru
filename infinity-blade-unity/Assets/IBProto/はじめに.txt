IB風ゲーム（IBProto）フォルダの見方

■ まず開くもの
メニュー「IBProto > シーンを開く」から
・戦闘（Battle）……バトルの試作。▶で遊べる
・キャラ確認（CharaView）……キャラを回して眺めるだけ

■ フォルダ
Scenes ……シーン（ゲームの「場面」）だけ
Characters
　Samurai ……武士キャラ。SamuraiCharacter が本体（プレハブ）
　　Meshes / Materials / Textures ……形・色・模様（自動で作られる。手で触らなくてOK）
　SF ……前に作ったSF鎧キャラの色
Motions ……動きの素材置き場。ファイル名＝動きの名前
　<ジャンル> ……女剣士・男騎士 など、どんなキャラ向けの動きか
　　<ダウンロード元・パック> ……どこから持ってきた素材のまとまりか
　女剣士 / Mixamo_GreatSword ……Mixamo の大剣パック（51個）
　台帳.csv ……どの動きが何か（日本語名・種類・ループ・出典）の控え帳
Scripts ……プログラム
　Battle ……戦闘（敵・主人公・カメラ・ゲーム進行）
　Common ……共通の道具（入力・効果音・図形づくり）
　Viewer ……キャラ確認用
Editor ……Unityのメニューに出るツール（武士キャラを生成 など）
　Setup ……最初に一度だけ動いたインストーラ
Old ……もう使っていないもの。消してもゲームは動く

■ Unityの画面
ヒエラルキー ……今のシーンに置いてある物の一覧
プロジェクト ……ファイル置き場（このフォルダ）
インスペクター ……選んだ物の設定
選ぶのは「ヒエラルキー」か「プロジェクト」、いじるのは「インスペクター」

■ 戦闘の操作
マウスでドラッグ：斬る／敵の攻撃中は矢印の方向へドラッグでパリィ
A / D：回避　S・Shift・右クリック長押し：ガード　F1：自動プレイ

■ モーション（動き）
メニュー「IBProto > モーション > モーション一覧」
（キャラ一覧の「モーション」ボタンからも開ける）
・キャラ一覧でキャラを開く → ▶で試しに再生（キャラ自体は変わらない。止めると元に戻る）
・「＋ 付ける」でそのキャラの持ち技リストに入る（Characters/<キャラ>/<キャラ>_Motions）
・新しい動きは Motions/<ジャンル>/<パック>/ に FBX を置いて Ctrl+R。自動で人型として読み込まれる
・上のタブでジャンル → 種類 の順に絞り込める
・Mixamo の動きはゲームに入れて使うのはOK。素材ファイルそのものを配るのはNG

■ 居合バトル（新しい戦闘）
メニュー「IBProto > 居合バトル > シーンを開く」→ ▶
・左クリック長押し：納刀（シュ… → コッ）　→　マウスを振る：その向きへ抜刀
・敵の太刀筋を迎え撃つ向きに抜くと弾く（◀▶は同じ向き、▲は上へ振る）。赤い「！」の突きは A / D でかわす
・弾き続けると敵の体勢が崩れる。崩れている間だけ斬れる
・門守は、構えの向きを途中で切り替える「フェイント」や、溜めの長い一太刀も使う。目印（◀▶▲）も切り替わるので、最後まで見てから抜く
　攻撃の並びは IaiGame.cs の P1（前半）・P2（怒り）で決めている。Atk('L', 1.3f, 'R') ＝ 右と見せて左、1.3秒で当たる
・勝つと戦績（腕前・時間・弾き・冴え・見切り・被弾）が出る。最速の時間はPCに保存され、タイトルにも出る（自動プレイを使った戦いは数えない）
・F1：自動プレイ　F2：攻撃の向きの目印を出す／消す
・キャラ：Characters/Tabibito（主人公・旅の抜刀者）、Characters/Kadomori（ボス・門守）。キャラ一覧から開ける
・姿勢（ポーズ）はプレハブの IaiPuppet に保存されている。骨アニメは使っていない
・音：Iai/Audio の音声ファイル。同じ名前のファイルで上書きすれば音が替わる
・手触りの数字：シーンの Game を選んで、インスペクターの「手触り」「強さ」
・形の元：Blender/scripts/iai（hero.py / boss.py）。直したら Iai/Source の json を差し替えて
　「IBProto > 居合バトル > キャラを取り込み直す」
・ClaudeBridge フォルダ：Claude が画面を触らずに確認するための連絡用（消してもゲームは動く）
